# diadelfo.com

Personal landing page for Matteo Diadelfo — operator who builds with AI.

Static single-page site. No build step. Tailwind via CDN, Web3Forms backend.

## Local preview

```bash
python3 -m http.server 4747
```

Open http://localhost:4747

## Deploy

Hosted on Vercel. Pushes to `main` auto-deploy.
